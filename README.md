Emberline is a round-based tactical FPS built with three.js: defenders hold two bomb sites on the original Foundry Yard map while attackers push three lanes to plant. Five-round matches, a buy menu with money, three weapons, frag grenades, and bots that see, hear, and shoot back.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
